# SmartNest AI — DevOps Project

An AI-powered Smart Apartment Resource Management Platform.

## Project Goals
- Automate apartment maintenance workflows.
- Manage resident complaints and visitor entry.
- Track maintenance tasks and facility bookings.
- Integrate AI for smart complaint analysis.

## DevOps Tools
- Git and GitHub
- Jenkins for CI/CD
- Docker for containerization
- Selenium for automated browser testing
- AWS for deployment
